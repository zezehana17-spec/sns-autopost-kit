# SNS 자동 발행 키트 (sns-autopost-kit)

> **베타 테스트 중이에요.** 아직 처음 써 보는 분들과 함께 다듬고 있어요. 막히는 곳이 있으면 [이슈](https://github.com/zezehana17-spec/sns-autopost-kit/issues/new?template=stuck.md)로 알려 주세요. 사용하시는 Claude가 대신 남겨도 됩니다.

카페·식당·여행지에서 사진과 영상만 찍어 보내면, Claude가 릴스·카드뉴스·글로 편집하고
인스타그램·스레드에 자동으로 올려 주는 키트입니다.

- 내가 하는 일: 사진·영상 찍기, 한 줄 평 쓰기, 승인 누르기
- Claude가 하는 일: 편집(자막·음악 포함), 글쓰기, 주소·영업정보 찾기, 발행 예약
- 비용: 전부 무료 플랜으로 동작 (Claude 유료 플랜만 필요)

---

## 준비물 (이것만 있으면 됩니다)

1. Claude 유료 플랜 (claude.ai)
2. 크롬 브라우저 + Claude in Chrome 확장 프로그램
3. 인스타그램 계정 (없으면 Claude가 만드는 걸 도와줍니다)

GitHub, Vercel, 메타 개발자 가입은 Claude가 순서대로 열어서 진행합니다.
비밀번호·인증번호 입력과 "진행할까요?"에 답하는 것만 직접 하시면 됩니다.

---

## 시작하기

Claude 대화창에 아래 문장을 그대로 붙여 넣으세요.

```
이 저장소의 SETUP.md를 읽고, 크롬에서 순서대로 내 SNS 자동 발행을 세팅해 줘.
가입·토큰·배포처럼 중요한 단계는 누르기 전에 나한테 물어봐 줘.
저장소 주소: https://github.com/zezehana17-spec/sns-autopost-kit
```

세팅은 보통 1~2시간 걸립니다. 대부분은 메타(인스타·스레드) 토큰 받는 시간입니다.

---

## 세팅이 끝나면

- Claude 프로젝트 "내 SNS 편집실"에 사진·영상과 한 줄 평을 보내세요.
  예: `카페 / 곤지암 ○○카페 / 창가 뷰 좋음, 파스타 맛있음, 이번 달만 3번 감`
- Claude가 완성본을 만들어 보여 주고, 이 저장소에 올리면 30분 안에 발행됩니다.
- 관리 화면(배포 주소/admin)에서 예약·발행 상태를 보고, 발행 전이면 멈출 수 있습니다.

## 선생님이라면 (수업 표현 카드)

세팅은 똑같이 위 문장으로 시작하세요. Claude가 "어떤 용도로 쓰세요?"라고 물으면 "수업 표현 카드"라고 답하면 됩니다.
가입부터 첫 발행까지는 같고, 편집실 지침만 강사 편(EDITING-teacher.md)으로 바뀝니다.

- 무엇을 올릴지, 몇 장으로, 어떤 색과 구성으로 할지는 선생님이 정해요. 처음에 Claude가 물어보고 기억해 둡니다.
- 색은 테마(navy, forest, coral, mono, sky, rose, mint)에서 고르거나 내 브랜드 색을 그대로 쓸 수 있어요.
- 캔바 등에서 직접 만든 이미지를 그대로 올려도 됩니다.
- 이후에는 수업 메모 한 줄(예: `오늘 표현 give it a shot / 3장`)만 보내면 Claude가 카드를 만들어 보여 주고, 좋다고 하면 예약 발행돼요.

## 막혔을 때

Claude에게 "막힌 내용을 이 저장소에 이슈로 남겨 줘"라고 하세요. Claude가 SETUP.md의 "막혔을 때" 규칙대로 개인정보를 빼고 정리해서 남깁니다.
만든 사람이 이슈를 보고 지침을 고치면, 다음 사람부터는 같은 곳에서 막히지 않아요.

## 내 방식대로 바꾸기

복사해 간 저장소는 여러분 것이에요. Claude에게 "이걸 기반으로 내 방식대로 바꾸자"라고 하면 지침과 코드를 고쳐 가며 쓰실 수 있어요.
(예: 카드뉴스 색을 내 브랜드로, 계정 여러 개, 글 말투 바꾸기)

원본이 업데이트되면 Claude에게 이렇게 말하세요.

```
원본 저장소 https://github.com/zezehana17-spec/sns-autopost-kit 에서 바뀐 것을 확인하고,
내가 바꾼 부분은 지키면서 필요한 것만 내 저장소에 가져와 줘.
```
